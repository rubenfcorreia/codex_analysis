# Usage

Preferred entrypoints:

```bash
python -m analysis.soma_bouton_pipeline --config analysis/soma_bouton_pipeline/soma_bouton_pipeline_config.json
```

or:

```bash
python analysis/soma_bouton_pipeline/run_soma_bouton_pipeline.py --config analysis/soma_bouton_pipeline/soma_bouton_pipeline_config.json
```

The implementation file `soma_bouton_pipeline.py` is kept as the modular
pipeline core.
