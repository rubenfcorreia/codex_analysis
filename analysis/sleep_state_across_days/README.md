# Sleep State Across Days Launcher

This folder contains the organized entry point for the sleep-state-only across-days workflow.
It hands off to the root script so the defaults and imports stay unchanged.

## Launcher

- `sleep_state_across_days.py`

## Example

```bash
python3 /home/rubencorreia/code/codex_analysis/analysis/sleep_state_across_days/sleep_state_across_days.py \
  --config /home/rubencorreia/code/codex_analysis/analysis/sleep_state_across_days/sleep_state_across_days_config.json
```
